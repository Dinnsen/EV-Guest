## EV Guest v0.7.0

EV Guest is now a pure calculator. Charger control is removed; the plan is exposed through `binary_sensor.charge_now` and can feed EV Smart Charging.

### Removed
- Charger control: the **Enable Charger Control** switch and the **Charger Switch Entity** / **Charger Status Entity** settings
- Status attributes `charger_control_enabled`, `charger_entity`, `charger_status_entity`, `charger_is_on`, `language`

### Fixed
- `charge_now` now follows the exact planned interval instead of whole hours (a plan ending at 03:20 turns off at 03:20, not 04:00), and updates exactly at each start and end
- A running plan no longer moves when prices update. Because EV Guest only knows the start SoC, recalculating a running plan made it slide forward and charge the same energy twice. Automatic recalculation now only happens before the plan starts; **Calculate** always makes a new plan
- Split charging puts the remaining part-hour on the cheapest remaining hour instead of the latest chosen hour, joins it to a neighbouring charging hour when possible, and no longer plans an hour that ends after the completion time
- Inputs and the current plan survive a Home Assistant restart
- A MotorAPI outage no longer stops EV Guest from starting

### Changed
- The MotorAPI key is optional. Without it, enter battery capacity manually
- An invalid MotorAPI key during lookup starts reauthentication instead of raising an error
- `binary_sensor.charge_now` is no longer a diagnostic entity
- Price updates no longer create a plan before you have pressed **Calculate** once
- New status attributes: `charging_segments` (exact intervals) and `plan_locked`
- README: new sections on charging the car, EV Smart Charging and live SoC

### Upgrade notes
- The **Enable Charger Control** switch is removed from the entity registry automatically. Remove it from dashboards and automations
- If you relied on EV Guest to switch a charger, create an automation that follows `binary_sensor.ev_guest_charge_now`
- Press **Calculate** once after upgrading; plans from 0.6.x were not stored

### Rollback
The config entry version is unchanged (7) and the old charger settings are kept untouched, so downgrading to 0.6.5 works. Entries created on 0.7.0 without a MotorAPI key will not start on 0.6.5, which requires a key.
