## EV Guest v0.8.0

EV Guest now follows Home Assistant's integration quality guidelines: native entity types, translated errors and states, reconfiguration, repairs, and a test suite that runs against real Home Assistant.

### Breaking changes
- **Charge start time** and **Charge end time** are now timestamp sensors (shown in your local format) instead of text like `22:00`.
- **Charge time** is now a duration in minutes instead of text.
- **Status** is now an enum with translated states: `ready`, `planned`, `charging`, `completed`, or the reason the last calculation failed (`invalid_input`, `limit_not_above_soc`, `no_price_data`, `not_enough_prices`, `no_window`). Lookup errors are shown as error messages instead.
- **Charge completion time** is now a time entity (`time.ev_guest_charge_completion_time`) instead of a text entity. The old text entity is removed automatically; update dashboards and automations that use it.
- The **clock format** and **charge time format** settings are gone; Home Assistant formats times and durations itself.
- Actions take `config_entry_id` (optional with one EV Guest). `entry_id` still works.

### New
- **Reconfigure** to change the price sensor, country or MotorAPI key; **Configure** for the currency. Changes apply without a restart.
- The price sensor is checked during setup.
- A repair issue appears when the price sensor no longer exists.
- Errors from buttons and actions are shown in the UI and translated, e.g. *Enter a license plate first*.
- All entity names, states, actions, errors and setup fields are translated (English and Danish). Entity names are now Danish in a Danish Home Assistant.
- Icons per state, e.g. for *Charge now* and *Status*.
- Device classes: battery (SoC, charge limit), power, energy storage, monetary, timestamp and duration.
- Currency defaults to your Home Assistant currency.
- Diagnostics include the plan status.

### Fixed
- Entity names were always English; the Danish translations are now used.
- Option changes needed a restart.
- When a lookup failed, the car sensors kept showing as available.

### Under the hood
- No polling: updates come from inputs, price changes and the plan's own start/end times.
- 107 tests against real Home Assistant (pytest-homeassistant-custom-component), 99 % coverage, required ≥ 95 % in CI.
- Ruff lint and format checks, Dependabot, issue templates, `quality_scale.yaml`.
- Releases get an `ev_guest.zip` for manual installation.

### Upgrade notes
- Update dashboard cards that use `text.ev_guest_charge_completion_time` to `time.ev_guest_charge_completion_time`.
- Cards showing start/end time now show a date and time.

### Rollback
The config entry is migrated to version 7.1, which 0.7.x still loads. Downgrading recreates the old text entity.
