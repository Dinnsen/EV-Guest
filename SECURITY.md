# Security

🇩🇰 Dansk nedenfor.

## Supported versions

Only the latest release gets fixes. Update through HACS.

## Reporting a vulnerability

Please **do not** open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/Dinnsen/EV-Guest/security/advisories/new)
with a description and, if possible, how to reproduce it. Don't include your
MotorAPI key.

You will get an answer within a week. Once fixed, a new release is published and the
advisory is made public with credit, if you want it.

What EV Guest does with your data is described under *Privacy* in the
[README](README.md#privacy).

---

## Sikkerhed

Kun den nyeste udgivelse får rettelser. Opdatér via HACS.

Opret **ikke** et offentligt issue. Rapportér sårbarheden privat via
[GitHubs private sårbarhedsrapportering](https://github.com/Dinnsen/EV-Guest/security/advisories/new)
med en beskrivelse og gerne hvordan den kan genskabes. Medsend ikke din MotorAPI-nøgle.

Du får svar inden for en uge. Når fejlen er rettet, udgives en ny version, og
rapporten gøres offentlig med kreditering, hvis du ønsker det.
